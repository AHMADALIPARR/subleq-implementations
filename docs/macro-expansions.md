# sasm macro expansions

Generated by `racket asm/macro-table.rkt --expansions > docs/macro-expansions.md`.
Each line `sq a b c` is one SUBLEQ instruction (M[b] -= M[a]; if M[b] <= 0 goto c).
`next` is the following instruction, `Kv` is the constant cell holding v (`K0` is Z),
names such as `M1`, `P3`, `U7` are labels generated by the assembler, and `x+5` is cell x + 5.
Costs are in docs/sha256-keystream-whitepaper.md, section 4.
